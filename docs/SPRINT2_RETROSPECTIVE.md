# Sprint 2 Retrospective

## Sprint Goal

Develop the ETL pipeline to collect, clean, transform, and load Nifty 100 financial data into the SQLite database.

---

## Completed

- Designed the SQLite database schema.
- Created database tables for companies, financial statements, sectors, market capitalization, peer groups, and supporting datasets.
- Developed ETL scripts for data extraction and transformation.
- Loaded historical financial data into SQLite.
- Validated database integrity and relationships.
- Performed data cleaning and preprocessing.
- Implemented logging and error handling during ETL execution.

---

## Challenges

- Handling inconsistent source data formats.
- Managing missing values across multiple datasets.
- Resolving duplicate company records.
- Maintaining referential integrity across related tables.

---

## Improvements

- Automate incremental data refresh.
- Improve ETL execution speed.
- Add validation reports after every ETL run.
- Improve logging and monitoring.

---

## Sprint Outcome

Sprint 2 objectives were successfully completed with a fully populated SQLite database ready for analytics.
